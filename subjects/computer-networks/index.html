03 / FOUNDATIONAL TERMINOLOGY & TAXONOMY

Core Definitions & Classifications

Standardized academic definitions and structural classifications essential for conceptual questions:

Bandwidth-Delay Product (BDP) Transport Metrics

Capacity of a network link measured as Bandwidth x Round-Trip Time (RTT). Represents maximum data in flight.

Note: TCP window must be at least BDP to fully saturate link capacity.
CSMA/CD Minimum Frame Size Medium Access

Frame transmission time must be at least twice the one-way propagation delay: T_t >= 2 T_p, giving L_{min} = 2 * T_p * Bandwidth.

Note: Ensures sender detects collisions before transmission completes.
Classless Inter-Domain Routing (CIDR) IP Addressing

Address allocation method using prefix notation /n. Number of host addresses = 2^{32-n} - 2.

Note: Routers forward packets using Longest Prefix Matching.
Count-to-Infinity Problem Routing

Routing anomaly in Distance Vector (Bellman-Ford) routing where link failure causes nodes to slowly increment distance metrics to infinity.

Note: Partially mitigated by Split Horizon and Poison Reverse.
TCP AIMD Dynamics Congestion Control

Additive-Increase Multiplicative-Decrease: cwnd increases linearly by +1 MSS per RTT in congestion avoidance, and halves on packet loss.

Note: Mathematically guarantees convergence to both efficiency and fairness.
Routing Protocol Architecture Taxonomy Network Layer
  • Distance Vector (RIP - RFC 2453): Bellman-Ford algorithm; exchanges vectors with direct neighbors; suffers from Count-to-Infinity (split horizon fix).
  • Link State (OSPF - RFC 2328): Dijkstra's shortest-path tree; floods link-state advertisements (LSAs) across entire area; fast convergence.
  • Path Vector (BGP-4 - RFC 4271): Inter-domain routing across Autonomous Systems (AS); tracks complete AS-path attribute to prevent routing loops.
  • Static vs Dynamic Routing: Static configured manually by admin; dynamic adapts automatically to link failures and network topology shifts.
Sliding Window Flow Control Archetypes Transport Layer
  • Stop-and-Wait ARQ: Sender transmits 1 frame and waits for ACK; efficiency eta = 1 / (1 + 2a), where a = T_prop / T_trans.
  • Go-Back-N ARQ: Sender window size W_s = 2^k - 1, receiver window W_r = 1; cumulative ACKs; discards all out-of-order frames.
  • Selective Repeat ARQ: Sender window W_s = 2^{k-1}, receiver window W_r = 2^{k-1}; individual ACKs; retransmits ONLY corrupted frames.
  • TCP Flow Control: Dynamic sliding receiver window (rwnd) advertised in header; prevents fast sender from overflowing receiver socket buffer.
04 / IN-DEPTH SYLLABUS MODULES

Core Theoretical Modules

Comprehensive subject breakdown containing foundational principles, key theorems, and common examination pitfalls.

MODULE 01

Network Architecture, Delays & Sliding Window Protocols

  • Packet Delays: Transmission delay T_t = L / Bandwidth; Propagation delay T_p = Distance / Speed.
  • Efficiency parameter a = T_p / T_t. Stop-and-Wait efficiency eta = 1 / (1 + 2a).
  • Go-Back-N: Sender window W_s = 2^k - 1, receiver window W_r = 1. Retransmits all unacknowledged frames on packet loss.
  • Selective Repeat: W_s = W_r = 2^{k-1}. Individual retransmission and ACK buffering at receiver.
Essential Theorem & Principle CSMA/CD Minimum Frame Size: In CSMA/CD Ethernet networks, frame transmission time must be at least twice the one-way propagation delay: T_t >= 2 T_p, which gives L_{min} >= 2 * T_p * Bandwidth.
⚠️ GATE Exam Trap & Common Mistake Sequence Number Bit Width Trap: In Go-Back-N with k-bit sequence numbers, max sender window is 2^k - 1, NOT 2^k. In Selective Repeat, max window is 2^{k-1} to avoid stale packet confusion.
MODULE 02

Network Layer, IPv4 Subnetting & Routing Algorithms

  • IPv4 header size: 20 bytes minimum up to 60 bytes with options (IHL field in 4-byte words).
  • Fragmentation: Fragment Offset field is measured in units of 8-byte blocks.
  • CIDR Subnetting: /n prefix has 2^{32-n} total addresses and 2^{32-n} - 2 usable host addresses.
  • Distance Vector routing uses distributed Bellman-Ford; susceptible to Count-to-Infinity. Link State uses Dijkstra.
Essential Theorem & Principle Longest Prefix Match Invariant: When an IP packet matches multiple forwarding table entries of different netmasks, the router MUST route the packet using the entry with the longest prefix length.
⚠️ GATE Exam Trap & Common Mistake IPv4 Fragment Offset Scaling: The Fragment Offset field in the IPv4 header does NOT count single bytes! It counts 8-byte blocks. Always divide byte offset by 8 when calculating the offset field value.
MODULE 03

Transport Layer, TCP Dynamics & Congestion Avoidance

  • TCP flow control: Receiver advertises rwnd in header. Sender window is min(cwnd, rwnd).
  • Slow Start: cwnd starts at 1 MSS and doubles every RTT (cwnd = cwnd + 1 MSS per received ACK).
  • Congestion Avoidance: When cwnd >= ssthresh, grows linearly by +1 MSS per RTT.
  • Loss Events: Timeout resets cwnd = 1 MSS and restarts Slow Start. 3 Duplicate ACKs halving cwnd (Fast Recovery).
Essential Theorem & Principle TCP AIMD Convergence Principle: Additive-Increase Multiplicative-Decrease ensures distributed bandwidth sharing among competing TCP flows converges to both efficiency and fairness.
⚠️ GATE Exam Trap & Common Mistake Timeout vs 3-Dup-ACK Trap: A timeout indicates severe network congestion and drops cwnd all the way to 1 MSS. In contrast, 3 Duplicate ACKs indicate mild packet loss and drop cwnd to ssthresh without resetting to 1.
05 / CANONICAL COMPARISON MATRIX

TCP (Transmission Control Protocol) vs. UDP (User Datagram Protocol)

Detailed architectural and mathematical comparison of fundamental contrasting concepts frequently tested in GATE:

COMPARISON DIMENSION TCP (RFC 793 / RFC 5681) UDP (RFC 768)
Connection Establishment Connection-oriented; requires 3-way handshake (SYN, SYN-ACK, ACK) before data transfer. Connectionless; datagrams transmitted immediately with zero handshake delay.
Reliability & Ordering Guaranteed delivery, in-order byte stream, checksum, cumulative ACKs, retransmissions. Best-effort unreliable datagram delivery; packets may be lost, duplicated, or reordered.
Congestion & Flow Control Implements receiver window (rwnd) flow control and sender congestion window (cwnd). Zero congestion control and zero flow control; transmits at application generation rate.
Header Protocol Overhead 20 bytes baseline header (up to 60 bytes with TCP options like MSS, Window Scale, SACK). 8 bytes fixed header (Source Port, Destination Port, Length, Checksum).
Transmission Semantics Continuous byte-stream; application message boundaries are not preserved. Message-oriented; preserves application packet boundaries intact.
GATE Examination Pitfall TCP sequence numbers count BYTES transmitted, NOT packets. SYN and FIN consume 1 sequence number each. UDP checksum is optional in IPv4, but strictly mandatory in IPv6.
06 / MATHEMATICAL FORMULATION

TCP Congestion Control & IPv4 Subnetting

Computer Networks 
TCP Congestion Window Dynamics (AIMD):
  Slow Start: cwnd = cwnd + 1 MSS per ACK (Exponential Growth until ssthresh)
  Congestion Avoidance: cwnd = cwnd + (1 / cwnd) per ACK (Linear Increase +1 MSS per RTT)
  On 3 Duplicate ACKs (Fast Retransmit/Fast Recovery):
    ssthresh = max(2, cwnd / 2), cwnd = ssthresh + 3
  On Timeout:
    ssthresh = max(2, cwnd / 2), cwnd = 1 MSS

CIDR Host Calculation:
  Usable Hosts in /n Subnet = 2^(32 - n) - 2 (subtract Network ID and Broadcast)
