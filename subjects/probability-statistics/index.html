01 / CONCEPTUAL FOUNDATION

Start with the fundamentals

Conditional probability is P(A|B)=P(A∩B)/P(B), provided P(B)>0. If P(A∩B)=0.2 and P(B)=0.5, then P(A|B)=0.4. Independence is different from mutual exclusivity.

03 / FOUNDATIONAL TERMINOLOGY & TAXONOMY

Core Definitions & Classifications

Standardized academic definitions and structural classifications essential for conceptual questions:

Axiomatic Probability Probability Foundations

Probability measure P assigning values in [0, 1] to events, where P(S) = 1 and P(A v B) = P(A) + P(B) for mutually exclusive events.

Note: Complement rule: P(A’) = 1 - P(A). General addition: P(A v B) = P(A) + P(B) - P(A cap B).
Conditional Probability & Bayes’ Rule Inference

P(A|B) = P(A cap B) / P(B) for P(B) > 0. Bayes’ rule inverts conditional dependencies: P(A_i|B) = [P(B|A_i)P(A_i)] / sum P(B|A_j)P(A_j).

Note: Critical for updating belief distributions upon receiving noisy evidence.
Central Limit Theorem (CLT) Asymptotic Theory

The normalized sum (or sample mean) of n independent identically distributed random variables with mean mu and finite variance sigma^2 approaches a standard normal distribution N(0, 1) as n -> inf.

Note: Holds regardless of whether the original distribution was skewed, uniform, or discrete.
Covariance & Correlation Bivariate Moments

Cov(X, Y) = E[(X - mu_X)(Y - mu_Y)] = E[XY] - E[X]E[Y]. Pearson correlation rho = Cov(X, Y) / (sigma_X sigma_Y) bounded in [-1, +1].

Note: Independence implies Cov = 0, but Cov = 0 does NOT guarantee independence.
Hypothesis Testing & p-value Statistical Inference

Decision framework evaluating null hypothesis H_0 against alternative H_1. The p-value is the probability of observing data at least as extreme as the sample, assuming H_0 is true.

Note: Reject H_0 iff p-value <= alpha (significance level).
Discrete Probability Distributions Discrete Models
  • Bernoulli(p): Single trial with success probability p; Mean = p, Variance = p(1 - p).
  • Binomial(n, p): Number of successes in n independent Bernoulli trials; Mean = np, Var = np(1 - p).
  • Poisson(lambda): Rare event count in continuous interval; Mean = lambda, Var = lambda (equi-dispersed).
  • Geometric(p): Number of Bernoulli trials until first success; Mean = 1/p, memoryless property P(X > s + t | X > s) = P(X > t).
Continuous Distribution Archetypes Continuous Models
  • Uniform(a, b): Flat density f(x) = 1/(b - a); Mean = (a + b)/2, Variance = (b - a)^2 / 12.
  • Exponential(lambda): Waiting time between Poisson arrivals; Memoryless continuous model; Mean = 1/lambda, Var = 1/lambda^2.
  • Gaussian Normal(mu, sigma^2): Bell-shaped density governed by Central Limit Theorem (CLT); 68-95-99.7 empirical rule.
  • Standard Normal Z ~ N(0, 1): Standardized variable Z = (X - mu)/sigma; symmetric around 0.
04 / IN-DEPTH SYLLABUS MODULES

Core Theoretical Modules

Comprehensive subject breakdown containing foundational principles, key theorems, and common examination pitfalls.

MODULE 01

Axiomatic Probability, Independence & Bayes’ Theorem

  • Axioms: P(S) = 1, P(A) >= 0, and P(A v B) = P(A) + P(B) for mutually exclusive events.
  • Conditional probability: P(A|B) = P(A cap B) / P(B), provided P(B) > 0.
  • Independence: Events A and B are independent iff P(A cap B) = P(A) P(B).
  • Law of Total Probability: P(B) = sum P(B|A_i) P(A_i) across a partition {A_i} of sample space S.
Essential Theorem & Principle Bayes’ Inversion Rule: For a partition of the sample space into mutually exclusive events A_1, ..., A_k, P(A_i|B) = [P(B|A_i) P(A_i)] / sum_{j=1}^k [P(B|A_j) P(A_j)].
⚠️ GATE Exam Trap & Common Mistake Independence vs Mutual Exclusivity: Mutually exclusive events with non-zero probability can NEVER be independent! If A and B cannot occur together, knowledge that B occurred guarantees A did not.
MODULE 02

Random Variables, Distributions & Moments

  • Binomial Distribution: P(X=k) = C(n,k) p^k (1-p)^{n-k}; Mean = np, Variance = np(1-p).
  • Poisson Distribution: P(X=k) = (lambda^k e^{-lambda}) / k!; Mean = lambda, Variance = lambda.
  • Exponential Distribution: f(x) = lambda e^{-lambda x}; Memoryless property: P(X > s+t | X > s) = P(X > t).
  • Normal Distribution: Bell-shaped curve symmetric around mu; standard normal Z = (X - mu)/sigma.
Essential Theorem & Principle Linearity of Expectation: For ANY random variables X and Y (whether independent or dependent), E[aX + bY] = a E[X] + b E[Y].
⚠️ GATE Exam Trap & Common Mistake Variance Non-Linearity Trap: Var(X + Y) = Var(X) + Var(Y) + 2 Cov(X, Y). Do NOT drop the covariance term unless you are explicitly given that X and Y are uncorrelated or independent!
MODULE 03

Central Limit Theorem, Estimation & Hypothesis Testing

  • Sample Mean X_bar = (1/n) sum X_i has expected value mu and standard error sigma / sqrt(n).
  • Central Limit Theorem: Regardless of the underlying population distribution, the sample mean approaches normal distribution as n -> inf.
  • Hypothesis testing: Null hypothesis H_0 vs Alternative hypothesis H_1.
  • Type I Error (alpha): Rejecting H_0 when H_0 is true (false alarm). Type II Error (beta): Failing to reject H_0 when H_0 is false.
Essential Theorem & Principle Central Limit Theorem (CLT): The normalized sum of n independent identically distributed random variables with finite variance converges in distribution to the standard normal distribution N(0,1).
⚠️ GATE Exam Trap & Common Mistake P-Value Decision Boundary: Reject H_0 if and only if p-value <= alpha. If p-value > alpha, we "fail to reject H_0" (we NEVER say "we accept H_0").
05 / CANONICAL COMPARISON MATRIX

Binomial Distribution vs. Poisson Distribution

Detailed architectural and mathematical comparison of fundamental contrasting concepts frequently tested in GATE:

COMPARISON DIMENSION Binomial Distribution Bin(n, p) Poisson Distribution Poisson(lambda)
Support & Domain Finite discrete integers k in {0, 1, 2, ..., n}. Countably infinite discrete integers k in {0, 1, 2, 3, ...}.
Distribution Parameters Two parameters: trial count n and success probability p. Single parameter: arrival rate lambda = n * p.
Mean & Variance Relation Mean = np; Variance = np(1 - p). Variance is strictly LESS than Mean. Mean = lambda; Variance = lambda. Equi-dispersed: Mean equals Variance strictly.
Asymptotic Limiting Relation Converges to Poisson as n -> infinity, p -> 0 such that np = lambda remains constant. Arises as the continuous Poisson process count limit of independent rare Bernoulli trials.
Additive Convolution Property Sum of Bin(n1, p) + Bin(n2, p) is Bin(n1+n2, p) ONLY when p is identical. Sum of Poisson(lambda1) + Poisson(lambda2) is ALWAYS Poisson(lambda1 + lambda2).
GATE Examination Pitfall If variance exceeds mean (overdispersion), Binomial distribution cannot model the data. Poisson distribution has no upper bound; P(X = k) decreases as lambda^k / k! for large k.
06 / MATHEMATICAL FORMULATION

Bayes' Law & Central Limit Theorem

Probability Theory 
Bayes' Rule:
  P(A_i | B) = [ P(B | A_i) * P(A_i) ] / sum_{j=1}^k [ P(B | A_j) * P(A_j) ]

Central Limit Theorem (CLT):
  Given i.i.d random variables X_1, X_2, ..., X_n with mean mu and variance sigma^2:
  Sample Mean X_bar = (1/n) * sum(X_i)
  As n -> infinity:
  Z = (X_bar - mu) / (sigma / sqrt(n))  ---> N(0, 1)
