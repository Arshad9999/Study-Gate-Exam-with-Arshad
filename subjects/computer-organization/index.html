03 / FOUNDATIONAL TERMINOLOGY & TAXONOMY

Core Definitions & Classifications

Standardized academic definitions and structural classifications essential for conceptual questions:

Effective Access Time (EAT) Memory Subsystems

Average latency experienced by CPU when requesting memory, weighted by hierarchical hit rates: EAT = H * T_cache + (1 - H) * T_miss.

Note: In multi-level caches, miss penalty involves successive level latencies.
Operand Forwarding (Bypassing) Pipelining

Hardware optimization in pipelined processors routing ALU computation outputs directly back to earlier pipeline register inputs without waiting for register file writeback.

Note: Resolves ALU-to-ALU data hazards; cannot eliminate Load-to-Use 1-cycle stall.
Direct Memory Access (DMA) I/O Organization

Hardware controller transferring data blocks directly between high-speed peripheral I/O devices and main RAM without continuous CPU intervention.

Note: Cycle stealing mode steals isolated bus cycles; burst mode transfers entire blocks.
Spatial & Temporal Locality Cache Principles

Temporal locality: recently accessed memory locations are likely to be accessed again soon. Spatial locality: memory locations nearby recently accessed addresses are likely to be referenced.

Note: Cache line block size exploits spatial locality; cache size exploits temporal locality.
Amdahl’s Law Performance Bounds

Mathematical law stating the speedup of a system enhanced by factor s on fraction f is S = 1 / [(1 - f) + (f / s)].

Note: Maximum theoretical speedup is strictly bounded by 1 / (1 - f) as s -> inf.
Instruction Pipeline Hazards Pipelining Architecture
  • Structural Hazard: Resource contention when hardware cannot support multiple instructions simultaneously (e.g. unified memory).
  • Data Hazard (RAW - Read After Write): True data dependency where consumer instruction needs producer result before writeback; solved via operand forwarding.
  • Data Hazard (WAR & WAW): Name dependencies occurring only in out-of-order execution pipelines; solved via register renaming.
  • Control Hazard (Branch Penalty): Caused by branch/jump instructions altering PC; mitigated via dynamic branch predictors and delayed branch slots.
Cache Memory Placement Architectures Memory Hierarchy
  • Direct-Mapped Cache: Block maps to exactly (Block_Address mod Num_Lines); fast access but highest conflict misses.
  • Fully Associative Cache: Block can reside in ANY cache line; zero conflict misses but requires expensive parallel tag comparators.
  • K-Way Set Associative: Block maps to a specific set of K lines; balances lookup hardware complexity with low conflict miss rate.
  • Replacement Policies: LRU (Least Recently Used), FIFO (First-In First-Out), and Optimal (Belady's clairvoyant eviction).
04 / IN-DEPTH SYLLABUS MODULES

Core Theoretical Modules

Comprehensive subject breakdown containing foundational principles, key theorems, and common examination pitfalls.

MODULE 01

Instruction Set Architecture, Addressing Modes & Datapath

  • Instruction cycle: Fetch, Decode, Operand Fetch, Execute, Writeback.
  • Addressing modes: Immediate (#val), Direct (address in instruction), Indirect (@addr), PC-relative (PC + offset).
  • Control Unit: Hardwired control (fast, fixed combinational circuits) vs Microprogrammed control (flexible microinstructions, slower).
  • Interrupt handling: Hardware vectored interrupts save return PC and processor status word onto the system stack.
Essential Theorem & Principle PC-Relative Addressing Calculation: In PC-relative branch instructions, the effective branch target address is EA = Updated PC + Offset, where Updated PC is already pointing to the next instruction.
⚠️ GATE Exam Trap & Common Mistake Pre-Incremented PC Trap: When computing branch targets in PC-relative addressing questions, remember that the PC has ALREADY been incremented past the branch instruction before the offset is added!
MODULE 02

Memory Hierarchy, Cache Organization & Access Time

  • Locality of Reference: Temporal (reused recently) and Spatial (nearby memory items accessed together).
  • Cache address division for k-way set associative: Tag bits | Set Index bits (log2(Sets)) | Word Offset bits.
  • Number of sets = Total Cache Lines / k. In direct-mapped cache, k = 1; in fully associative cache, Sets = 1.
  • Cache write policies: Write-Through with write buffer vs Write-Back with dirty bit.
Essential Theorem & Principle Effective Memory Access Time: In a hierarchical cache system, EAT = H_1 T_1 + (1 - H_1) [H_2 (T_1 + T_2) + (1 - H_2) (T_1 + T_2 + T_{mem})].
⚠️ GATE Exam Trap & Common Mistake Simultaneous vs Hierarchical Access Trap: Check whether the problem specifies simultaneous cache-memory lookup or hierarchical lookup. In hierarchical lookup, the cache inspection time T_1 is added to the penalty.
MODULE 03

Instruction Pipelining, Hazards & Speedup Analysis

  • Classic 5-stage RISC pipeline: Instruction Fetch (IF), Instruction Decode (ID), Execute (EX), Memory (MEM), Writeback (WB).
  • Pipeline Hazards: Structural (resource conflicts), Data (RAW, WAR, WAW dependencies), Control (branch instructions).
  • Data Hazard Resolution: Operand forwarding (bypassing), software compiler scheduling, or hardware stalling (bubble insertion).
  • Pipeline Speedup: S = (n * k * clock) / [(k + n - 1 + Stalls) * clock]. As n -> inf with no stalls, S -> k.
Essential Theorem & Principle Amdahl’s Law for Speedup: S_{overall} = 1 / [(1 - f) + (f / s)], where f is the fraction of execution time enhanced by a speedup factor of s.
⚠️ GATE Exam Trap & Common Mistake Load-Use Data Hazard Trap: Operand forwarding CANNOT eliminate the stall between a Load Word (LW) instruction and an immediately following instruction that uses the loaded register. It requires at least 1 stall cycle!
05 / CANONICAL COMPARISON MATRIX

Write-Through Cache vs. Write-Back Cache

Detailed architectural and mathematical comparison of fundamental contrasting concepts frequently tested in GATE:

COMPARISON DIMENSION Write-Through Cache Write-Back Cache (Copy-Back)
Memory Update Strategy Updates written simultaneously to both cache line and main memory on every write hit. Updates written ONLY to cache block; main memory updated when block is evicted.
Status Bit Overhead No dirty bit required per cache line (only valid bit needed). Requires 1 dirty (modified) status bit per cache block to track modifications.
Memory Bus Write Traffic High bus traffic; every processor store generates a memory write cycle. Low bus traffic; memory write transactions occur only on eviction of dirty blocks.
Miss Allocation Strategy Typically paired with No-Write-Allocate (writes directly around cache to memory). Typically paired with Write-Allocate (fetches block into cache, then updates).
Fault Tolerance & Consistency Main memory is always completely synchronized with cache; clean recovery. Main memory contains stale data until eviction; requires write buffer on eviction.
GATE Examination Pitfall Write buffer stalls can degrade write-through performance if write bursts occur. A single read miss in write-back can cause TWO memory transactions if victim is dirty!
06 / MATHEMATICAL FORMULATION

Cache Memory EAT & Pipeline Speedup

Computer Architecture 
Effective Access Time (EAT) with Hierarchical Cache:
  EAT = H_1 * T_1 + (1 - H_1) * [ H_2 * (T_1 + T_2) + (1 - H_2) * (T_1 + T_2 + T_mem) ]
  where H_i = Hit Ratio at Level i, T_i = Access Latency.

Pipeline Speedup:
  Speedup S = Non-pipelined Time / Pipelined Time
            = (n * k * tau) / [ (k + n - 1) * tau + Stalls ]
  Ideal Limit (as n -> infinity, Stalls = 0): Speedup = k (number of stages)
