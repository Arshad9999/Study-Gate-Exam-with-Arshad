03 / FOUNDATIONAL TERMINOLOGY & TAXONOMY

Core Definitions & Classifications

Standardized academic definitions and structural classifications essential for conceptual questions:

Linear Independence Vector Spaces

A set of vectors {v_1, ..., v_k} is linearly independent iff c_1 v_1 + ... + c_k v_k = 0 holds strictly and only when all scalar coefficients c_i = 0.

Note: If any vector can be written as a linear combination of the others, the set is dependent.
Rank-Nullity Theorem Linear Transformations

For any linear mapping represented by an m x n matrix A, the dimension of the column space plus the dimension of the nullspace equals the number of columns: rank(A) + nullity(A) = n.

Note: Column space and row space always have the exact same dimension, called the rank.
Eigenvalues & Characteristic Roots Spectral Theory

Scalars lambda satisfying Av = lambda v for some non-zero eigenvector v, computed as roots of the characteristic polynomial det(A - lambda I) = 0.

Note: Trace(A) equals the sum of eigenvalues; Det(A) equals the product of eigenvalues.
Singular Value Decomposition (SVD) Decompositions

Factorization of an m x n real matrix into A = U Sigma V^T, where U (m x m) and V (n x n) are orthogonal matrices and Sigma contains non-negative singular values sigma_i = sqrt(lambda_i(A^T A)).

Note: SVD exists for ALL matrices regardless of shape, rank, or invertibility.
Positive Definite Matrix Quadratic Forms

A symmetric matrix A is positive definite iff x^T A x > 0 for all non-zero vectors x, or equivalently, iff all eigenvalues are strictly positive.

Note: Sylvester’s criterion: All leading principal minors must be strictly positive.
Matrix Canonical Classifications Matrix Theory
  • Symmetric Matrix (A = A^T): Real eigenvalues; orthogonal eigenvectors; orthogonally diagonalizable.
  • Orthogonal Matrix (Q^T Q = I): Orthonormal columns; preserves Euclidean length and dot products; det(Q) = ±1.
  • Idempotent Matrix (P^2 = P): Eigenvalues are strictly 0 or 1; represents oblique or orthogonal projections.
  • Nilpotent Matrix (A^k = 0 for some k): All eigenvalues are strictly 0; trace(A) = 0 and det(A) = 0.
The Four Fundamental Matrix Subspaces Subspace Topology
  • Column Space C(A) in R^m: Dimension = rank(r); spanned by pivot columns of A.
  • Null Space N(A) in R^n: Dimension = n - r (nullity); orthogonal complement to Row Space C(A^T).
  • Row Space C(A^T) in R^n: Dimension = rank(r); spanned by non-zero rows of RREF(A).
  • Left Null Space N(A^T) in R^m: Dimension = m - r; orthogonal complement to Column Space C(A).
04 / IN-DEPTH SYLLABUS MODULES

Core Theoretical Modules

Comprehensive subject breakdown containing foundational principles, key theorems, and common examination pitfalls.

MODULE 01

Linear Systems, Vector Spaces & Rank-Nullity Theorem

  • Linear system AX = B consistency: Consistent iff rank(A) = rank([A|B]). Unique solution iff rank = n; infinite solutions iff rank < n.
  • Homogeneous system AX = 0 always has trivial solution X = 0; non-trivial solutions exist iff det(A) = 0 (rank < n).
  • Vector spaces: Subspace test (closure under vector addition and scalar multiplication), linear independence, and spanning sets.
  • Basis and Dimension: A basis is a minimally spanning and maximally independent subset of vectors.
Essential Theorem & Principle Rank-Nullity Theorem: For any linear transformation represented by an m x n matrix A, the dimension of the column space plus the dimension of the null space equals the number of columns: rank(A) + nullity(A) = n.
⚠️ GATE Exam Trap & Common Mistake Underdetermined System Trap: If an m x n system has more variables than equations (n > m), it can NEVER have a unique solution. It either has infinitely many solutions (if consistent) or zero solutions (if inconsistent).
MODULE 02

Eigenvalues, Eigenvectors & Cayley-Hamilton Identity

  • Eigenvalue equation det(A - lambda I) = 0. Eigenvectors corresponding to distinct eigenvalues are linearly independent.
  • Trace(A) = sum(lambda_i) and det(A) = prod(lambda_i). Matrix is invertible iff zero is not an eigenvalue.
  • Eigenvalues of triangular and diagonal matrices are simply the entries along the main diagonal.
  • Diagonalizability: An n x n matrix is diagonalizable iff it possesses n linearly independent eigenvectors.
Essential Theorem & Principle Cayley-Hamilton Theorem: Every square matrix satisfies its own characteristic polynomial equation p(A) = 0, allowing efficient evaluation of matrix inverses A^{-1} and arbitrary high powers A^k.
⚠️ GATE Exam Trap & Common Mistake Geometric Multiplicity Trap: Do not assume a matrix is non-diagonalizable just because it has repeated eigenvalues. It is diagonalizable as long as the geometric multiplicity (nullity of A - lambda I) equals algebraic multiplicity for every eigenvalue.
MODULE 03

Orthogonal Projections, SVD & Quadratic Forms

  • Orthogonal projection of vector b onto column space of A: p = A (A^T A)^{-1} A^T b.
  • Singular Value Decomposition: A = U Sigma V^T, where U and V are orthogonal matrices and Sigma contains singular values.
  • Singular values sigma_i = sqrt(lambda_i(A^T A)) are always non-negative real numbers.
  • Quadratic forms Q(x) = x^T A x: Positive definite iff all eigenvalues are strictly positive (or all leading principal minors > 0).
Essential Theorem & Principle Spectral Theorem for Real Symmetric Matrices: Any real symmetric matrix A can be orthogonally diagonalized as A = Q Lambda Q^T, where all eigenvalues are real and eigenvectors are mutually orthogonal.
⚠️ GATE Exam Trap & Common Mistake Singular Values vs Eigenvalues: Unlike eigenvalues which can be negative or complex, singular values sigma_i are strictly real and non-negative. For symmetric matrices, singular values equal the absolute values of the eigenvalues.
05 / CANONICAL COMPARISON MATRIX

Diagonalization (Eigendecomposition) vs. Singular Value Decomposition (SVD)

Detailed architectural and mathematical comparison of fundamental contrasting concepts frequently tested in GATE:

COMPARISON DIMENSION Eigendecomposition (A = P D P^-1) Singular Value Decomposition (A = U Σ V^T)
Matrix Dimension Scope Strictly square matrices (n x n) only. Any arbitrary rectangular matrix (m x n).
Basis Vector Geometry Eigenvectors in P are not necessarily orthogonal (unless A is symmetric). Left singular vectors U (m x m) and right singular vectors V (n x n) are strictly orthonormal.
Existence Guarantee Exists iff A has n linearly independent eigenvectors (defective matrices cannot be diagonalized). Guaranteed to exist for EVERY real or complex matrix without exception.
Coordinate Transformations Applies a single coordinate basis change to both domain and codomain. Decouples into two distinct orthonormal coordinate systems for domain (R^n) and codomain (R^m).
Values Characterization Eigenvalues lambda_i can be complex, negative, or zero. Singular values sigma_i = sqrt(lambda_i(A^T A)) are always non-negative real numbers sorted in descending order.
GATE Examination Pitfall Invertibility does NOT imply diagonalizability (e.g. [[1,1],[0,1]] is invertible but non-diagonalizable). Rank of matrix equals the number of strictly non-zero singular values in Sigma.
06 / MATHEMATICAL FORMULATION

Eigenvalues & Singular Value Decomposition (SVD)

Linear Algebra 
Characteristic Equation: det(A - lambda * I) = 0
Properties of Eigenvalues lambda_i:
  1. sum(lambda_i) = Trace(A)
  2. prod(lambda_i) = det(A)
  3. A is invertible <=> lambda_i != 0 for all i
Singular Value Decomposition (SVD):
  A = U * Sigma * V^T
  U: m x m orthogonal matrix (eigenvectors of A * A^T)
  Sigma: m x n diagonal singular values sigma_i = sqrt(lambda_i(A^T A))
  V: n x n orthogonal matrix (eigenvectors of A^T * A)
