03 / FOUNDATIONAL TERMINOLOGY & TAXONOMY

Core Definitions & Classifications

Standardized academic definitions and structural classifications essential for conceptual questions:

Binary Search Tree (BST) Property Trees

For every node x: all keys in left subtree are strictly smaller than key(x), and all keys in right subtree are strictly larger than key(x).

Note: Inorder traversal of any valid BST produces strictly ascending sorted keys.
AVL Balance Factor Self-Balancing Trees

Height(LeftSubtree) - Height(RightSubtree). An AVL tree maintains BF in {-1, 0, +1} for every node through single (LL, RR) or double (LR, RL) rotations.

Note: Guarantees worst-case search, insertion, and deletion in O(log n) time.
Complete Binary Tree Tree Structures

A binary tree in which all levels are completely filled except possibly the last level, where nodes are positioned as far left as possible.

Note: Can be stored contiguously in an array without pointers: Parent(i) = floor((i-1)/2).
Activation Record (Stack Frame) Runtime Environments

A block of memory pushed onto the runtime call stack for each function invocation, storing parameters, local variables, return address, and saved registers.

Note: Recursion depth is limited by available call stack memory (stack overflow).
Catalan Number C_n Combinatorial Structures

Sequence defined by C_n = (1 / (n + 1)) * C(2n, n). Enumerates distinct binary search trees with n keys, valid parenthesis sequences, and stack permutations.

Note: C_3 = 5, C_4 = 14, C_5 = 42.
Self-Balancing Search Tree Taxonomy Search Trees
  • AVL Tree: Strictly height-balanced; balance factor in {-1, 0, +1}; maximum height <= 1.44 log_2 n; optimal for lookup-heavy workloads.
  • Red-Black Tree: Color-balanced; no two consecutive red nodes; equal black-height; maximum height <= 2 log_2(n+1); optimal for write-heavy workloads.
  • Splay Tree: Self-adjusting BST; splays accessed node to root via Zig-Zig and Zig-Zag rotations; amortized O(log n) performance.
  • B-Tree / B+ Tree: Multi-way balanced search trees with high branching factor; keeps disk I/O operations minimal for external storage.
Priority Queues & Heap Structures Priority Elements
  • Binary Min/Max Heap: Complete binary tree stored in contiguous array; Insert O(log n), Extract-Min O(log n), Build-Heap O(n).
  • Binomial Heap: Collection of binomial trees B_k with 2^k nodes; supports efficient Meld (Merge) in O(log n) time.
  • Fibonacci Heap: Relaxed tree forest; amortized O(1) Insert and Decrease-Key, O(log n) Extract-Min; optimal for Dijkstra/Prim.
  • Indexed Priority Queue: Maintains position mapping array enabling O(log n) Decrease-Key updates on arbitrary elements.
04 / IN-DEPTH SYLLABUS MODULES

Core Theoretical Modules

Comprehensive subject breakdown containing foundational principles, key theorems, and common examination pitfalls.

MODULE 01

C Language Semantics, Memory & Recursive Execution

  • Memory Layout: Code (text), Initialized data, BSS, Heap (grows up), Stack (grows down).
  • Pointer arithmetic: `p + 1` increments address by `sizeof(*p)` bytes. `a[i]` is identical to `*(a + i)`.
  • Operator Precedence: `*p++` evaluates to `*(p++)`, returning `*p` then incrementing pointer `p`. `(*p)++` increments the value.
  • Recursion: Each recursive call allocates a stack frame storing local variables, parameters, and return address.
Essential Theorem & Principle Array Dereferencing Identity: For any array `a` and index `i`, `a[i] == *(a + i) == *(i + a) == i[a]`.
⚠️ GATE Exam Trap & Common Mistake Dangling Pointer & Memory Leak: Freeing memory (`free(p)`) does not set `p` to NULL; dereferencing `p` afterward is undefined behavior. Failing to free dynamic memory causes memory leaks.
MODULE 02

Stacks, Queues & Linked List Invariants

  • Stack: LIFO structure used for function calls, expression evaluation, syntax matching, and DFS traversal.
  • Circular Queue: Array of size N implements modulo indexing. Full condition: `(rear + 1) % N == front`. Stores at most N - 1 items.
  • Linked List Reversal: Can reverse singly linked list in O(n) time and O(1) auxiliary space using 3 pointers (prev, curr, next).
  • Floyd’s Cycle Finding Algorithm: Slow pointer (1 step) and fast pointer (2 steps) meet inside cycle if a loop exists.
Essential Theorem & Principle Stack Permutation Bound: The number of distinct permutations of 1..n that can be produced using a stack is given by the n-th Catalan number C_n = (1 / (n + 1)) * C(2n, n).
⚠️ GATE Exam Trap & Common Mistake Infix to Postfix Associativity: When converting operators with equal precedence, left-associative operators (like +, -, *, /) cause operators on stack to pop; right-associative operators (like exponent ^) do not!
MODULE 03

Trees, Binary Search Trees & Self-Balancing AVL Trees

  • Binary Tree properties: Maximum nodes at depth d is 2^d. In any non-empty binary tree, n_0 = n_2 + 1 (leaves = degree-2 nodes + 1).
  • Unique Tree Construction: Requires Inorder traversal PLUS either Preorder or Postorder traversal.
  • Binary Search Tree (BST): Inorder traversal of a BST produces keys in strictly increasing sorted order.
  • AVL Tree: Self-balancing BST where height difference between left and right subtrees is at most 1 for every node.
Essential Theorem & Principle Binary Tree Degree Identity: In every binary tree, the number of leaf nodes n_0 is strictly equal to the number of nodes having two children n_2 plus one (n_0 = n_2 + 1).
⚠️ GATE Exam Trap & Common Mistake Tree Construction Ambiguity: You CANNOT reconstruct a unique binary tree from Preorder and Postorder traversals alone, unless you are explicitly given that every non-leaf node has exactly two children.
05 / CANONICAL COMPARISON MATRIX

AVL Tree vs. Red-Black Tree

Detailed architectural and mathematical comparison of fundamental contrasting concepts frequently tested in GATE:

COMPARISON DIMENSION AVL Tree (Strict Height-Balanced) Red-Black Tree (Color-Balanced)
Balance Invariant Condition Balance factor |height(Left) - height(Right)| <= 1 for EVERY node. No two red nodes adjacent; every path from root to null has equal black-height.
Maximum Tree Height Maximum height bounded strictly by 1.44 * log_2(n). Maximum height bounded by 2 * log_2(n + 1).
Lookup (Search) Performance Faster lookup times because strict balancing guarantees smaller average depth. Slightly slower lookup times due to larger allowable tree height.
Insertion Rebalancing Cost At most 2 tree rotations (single or double rotation) per insertion. At most 2 rotations per insertion; rest resolved via O(log n) recoloring.
Deletion Rebalancing Cost Can require up to O(log n) rotations cascading up to the tree root. At most 3 rotations per deletion; remaining rebalancing handled by recoloring.
GATE Examination Pitfall AVL trees are ideal for read-heavy / static dictionaries with infrequent insertions. Red-Black trees are preferred for write-heavy systems (C++ std::map, Linux scheduler).
06 / MATHEMATICAL FORMULATION

Binary Heap Invariant & AVL Balancing

Data Structures (C/C++) 
AVL Tree Balance Factor:
  BF(Node) = Height(LeftSubtree) - Height(RightSubtree)
  Tree is AVL balanced <=> BF in {-1, 0, +1} for ALL nodes.
  Rotations: LL (Single Right), RR (Single Left), LR (Left then Right), RL.

Binary Min-Heap Indexing (0-indexed array):
  Parent(i) = floor((i - 1) / 2)
  LeftChild(i) = 2*i + 1,  RightChild(i) = 2*i + 2
  Build-Heap Time: Sum_{h=0}^{log n} (n / 2^{h+1}) * O(h) = O(n)
