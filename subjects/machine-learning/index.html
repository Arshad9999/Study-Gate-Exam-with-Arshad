03 / FOUNDATIONAL TERMINOLOGY & TAXONOMY

Core Definitions & Classifications

Standardized academic definitions and structural classifications essential for conceptual questions:

Ordinary Least Squares (OLS) Regression

Linear model minimizing sum of squared residuals: w* = (X^T X)^{-1} X^T y. Under Gauss-Markov assumptions, OLS is the Best Linear Unbiased Estimator (BLUE).

Note: Requires X^T X to be non-singular and invertible.
Bias-Variance Decomposition Generalization

Expected test MSE decomposes into Bias^2 + Variance + Irreducible Noise. Complex models have low bias and high variance (overfitting); simple models have high bias and low variance.

Note: Regularization balances this tradeoff.
Support Vector Machine (SVM) Classification

Maximum-margin linear classifier maximizing geometric margin 2/||w|| between classes. Dual form depends only on dot products of support vectors.

Note: Kernel trick maps features implicitly into high-dimensional space via K(x, x’).
Information Gain Decision Trees

Reduction in Shannon Entropy achieved by partitioning data according to feature A: IG(S, A) = H(S) - sum (|S_v|/|S|) H(S_v).

Note: ID3 selects attribute maximizing IG; C4.5 uses Gain Ratio to penalize multivalued features.
Principal Component Analysis (PCA) Dimensionality Reduction

Unsupervised orthogonal linear projection maximizing data variance along principal axes given by eigenvectors of the sample covariance matrix.

Note: First component corresponds to largest eigenvalue lambda_1.
Supervised Learning Model Taxonomy Supervised Methods
  • Linear & Logistic Models: Linear regression for continuous outcomes; Logistic regression with Sigmoid link for binary class probabilities.
  • Support Vector Machines (SVM): Finds maximum-margin hyperplane separating classes; kernel trick maps data into higher-dimensional feature space.
  • Decision Trees & Ensembles: Greedy CART splitting on Gini impurity or Entropy; Bagging (Random Forests) vs Boosting (GBDT, XGBoost).
  • Multi-Layer Perceptrons (MLP): Deep feedforward neural networks trained with backpropagation (chain rule) and gradient descent.
Unsupervised Learning & Dimensionality Reduction Unsupervised Methods
  • K-Means Clustering: Partitioning algorithm iteratively updating cluster centroids; minimizes within-cluster sum of squares (WCSS / Inertia).
  • Hierarchical Agglomerative Clustering: Bottom-up tree of clusters (dendrogram); linkage criteria: single, complete, average, or Ward.
  • DBSCAN Density-Based: Discovers arbitrarily shaped clusters based on core points, epsilon-neighborhoods, and minPts; robust to noise.
  • Principal Component Analysis (PCA): Orthogonal linear projection onto directions of maximal variance (eigenvectors of covariance matrix).
04 / IN-DEPTH SYLLABUS MODULES

Core Theoretical Modules

Comprehensive subject breakdown containing foundational principles, key theorems, and common examination pitfalls.

MODULE 01

Linear Regression, Regularization & Model Validation

  • Ordinary Least Squares: Closed-form parameter solution w* = (X^T X)^{-1} X^T y.
  • Ridge Regression (L2): Adds lambda ||w||_2^2 penalty, solving w* = (X^T X + lambda I)^{-1} X^T y. Guarantees invertibility.
  • Lasso Regression (L1): Adds lambda ||w||_1 penalty, driving irrelevant feature weights to exactly zero (feature selection).
  • Bias-Variance Decomposition: Expected Test Error = Bias^2 + Variance + Irreducible Noise.
Essential Theorem & Principle Gauss-Markov Theorem: Under the conditions of zero error mean and homoscedasticity, the OLS estimator is the Best Linear Unbiased Estimator (BLUE), possessing the minimum variance among all linear unbiased estimators.
⚠️ GATE Exam Trap & Common Mistake Unscaled Feature Regularization: Always standardize/scale feature columns before applying Ridge or Lasso penalties! If features are unscaled, variables with large numerical values will be penalized disproportionately.
MODULE 02

Logistic Classification, Support Vector Machines & Kernels

  • Logistic Regression models probability P(Y=1|X) = 1 / (1 + e^{-w^T X}) using binary cross-entropy loss.
  • Support Vector Machines (SVM): Maximizes the geometric margin 2 / ||w|| between classes.
  • Soft-margin parameter C: High C penalizes misclassifications heavily (low bias, high variance); low C tolerates margin violations (high bias).
  • Kernel Trick: Implicitly maps input features into high-dimensional Hilbert space via Mercer kernel function K(x, x’).
Essential Theorem & Principle SVM Support Vector Sparsity: The optimal separating hyperplane depends solely on the support vectors (data points where Lagrange multipliers alpha_i > 0); removing all non-support vectors leaves the decision boundary unchanged.
⚠️ GATE Exam Trap & Common Mistake Accuracy on Imbalanced Datasets: High classification accuracy on severely imbalanced datasets (e.g., 99% negative class) is deceptive; always evaluate using Precision, Recall, and F1-Score.
MODULE 03

Decision Trees, Unsupervised Clustering & PCA

  • Entropy: H(S) = - sum p_i log_2 p_i. Information Gain IG(S, A) = H(S) - sum (|S_v|/|S|) H(S_v).
  • Gini Impurity: 1 - sum p_i^2 (used by CART). Faster to compute than entropy as it requires no logarithms.
  • K-Means Clustering: Iteratively assigns points to nearest centroid and recalculates centroid means. Sensitive to outliers and initialization.
  • Principal Component Analysis (PCA): Projects data onto orthogonal directions of maximum variance given by eigenvectors of the covariance matrix.
Essential Theorem & Principle PCA Variance Maximization: The first principal component corresponds to the eigenvector of the sample covariance matrix associated with the largest eigenvalue lambda_1, capturing the maximum possible data variance.
⚠️ GATE Exam Trap & Common Mistake K-Means Local Minima Trap: K-Means is guaranteed to converge, but only to a local optimum of the inertia objective. Running multiple restarts (K-Means++) with distinct initial centroids is required for robust results.
05 / CANONICAL COMPARISON MATRIX

L1 Regularization (Lasso) vs. L2 Regularization (Ridge)

Detailed architectural and mathematical comparison of fundamental contrasting concepts frequently tested in GATE:

COMPARISON DIMENSION L1 Regularization (Lasso) L2 Regularization (Ridge)
Loss Penalty Formulation Penalty = lambda * sum |w_i| (L1 norm of weight vector). Penalty = (lambda / 2) * sum w_i^2 (squared L2 norm of weight vector).
Constraint Geometry Diamond-shaped (rhombus) polyhedral contour with sharp vertices on coordinate axes. Smooth hyperspherical (circular) Euclidean contour without sharp corners.
Sparsity & Feature Selection Drives non-essential weights to EXACTLY ZERO (acts as automatic feature selection). Shrinks weights asymptotically toward zero, but NEVER sets weights strictly to zero.
Closed-Form Analytical Solution No closed-form solution (non-differentiable at w_i = 0); solved via subgradient or coordinate descent. Has closed-form analytical solution: w = (X^T X + lambda I)^-1 X^T y.
Collinear Features Behavior Arbitrarily selects one feature from a group of correlated features and zeros the rest. Retains all correlated features and shrinks their coefficients symmetrically.
GATE Examination Pitfall Lasso cannot select more features than the number of training samples n when n < d. Ridge ensures (X^T X + lambda I) is strictly positive definite and invertible even when X^T X is singular.
06 / MATHEMATICAL FORMULATION

Bias-Variance Decomposition & L2 Regularization

Statistical Machine Learning 
Mean Squared Error Decomposition for test point x:
  E[(y - f_hat(x))^2] = Bias[f_hat(x)]^2 + Var[f_hat(x)] + sigma_epsilon^2
where:
  Bias[f_hat(x)] = E[f_hat(x)] - f(x)
  Var[f_hat(x)]  = E[(f_hat(x) - E[f_hat(x)])^2]
  sigma_epsilon^2 = Irreducible environmental noise

Ridge Regression (L2 Penalty):
  w* = argmin_w ||X w - y||^2 + lambda * ||w||_2^2
  Closed-Form Solution: w* = (X^T X + lambda * I)^{-1} X^T y
  Adding lambda * I guarantees invertibility even when X^T X is singular!
