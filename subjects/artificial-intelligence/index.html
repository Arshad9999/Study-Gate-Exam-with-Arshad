03 / FOUNDATIONAL TERMINOLOGY & TAXONOMY

Core Definitions & Classifications

Standardized academic definitions and structural classifications essential for conceptual questions:

Heuristic Admissibility Search Theory

A heuristic h(n) is admissible iff it never overestimates the true cost to reach the goal: h(n) <= h*(n) for all nodes n.

Note: Guarantees A* tree search finds an optimal solution.
Heuristic Consistency (Monotonicity) Search Theory

For every node n and successor n’ generated by action a: h(n) <= c(n, a, n’) + h(n’). Satisfies triangle inequality.

Note: Guarantees A* graph search finds optimal paths without reopening closed nodes.
Alpha-Beta Pruning Adversarial Games

Adversarial search optimization maintaining alpha (MAX’s guaranteed lower bound) and beta (MIN’s guaranteed upper bound). Prunes subtree whenever beta <= alpha.

Note: With optimal move ordering, reduces search complexity from O(b^m) to O(b^{m/2}).
Arc Consistency (AC-3) Constraint Satisfaction

Variable X is arc-consistent with Y iff for every value in domain(X), there exists a legal value in domain(Y) satisfying the binary constraint.

Note: AC-3 eliminates domain values that can never participate in any valid solution.
Bayesian Belief Network (BBN) Probabilistic Reasoning

Directed Acyclic Graph (DAG) representing conditional independence relationships among random variables. Factorizes joint distribution: P(X_1, ..., X_n) = prod P(X_i | Parents(X_i)).

Note: D-separation determines conditional independence graphically.
State-Space Search Strategy Taxonomy Heuristic Search
  • Uninformed (Blind) Search: BFS (optimal for unit edge costs), DFS (low memory O(bm)), Uniform Cost Search (optimal for general positive costs).
  • Informed (Heuristic) Search: Greedy Best-First Search evaluates f(n) = h(n); A* Search evaluates f(n) = g(n) + h(n).
  • Iterative Deepening Search (IDS & IDA*): Combines completeness and optimality of BFS with linear space complexity O(bd) of DFS.
  • Local Search & Optimization: Hill Climbing (prone to local maxima and plateaus), Simulated Annealing (accepts worse moves probabilistically), Genetic Algorithms.
Adversarial Multi-Agent Game Search Game Theory
  • Minimax Algorithm: Optimal decision policy for deterministic, zero-sum, perfect-information 2-player games; time complexity O(b^m).
  • Alpha-Beta Pruning: Prunes branches that cannot influence final decision; worst case O(b^m), optimal move ordering achieves O(b^{m/2}).
  • Expectiminimax: Incorporates chance nodes (dice rolls, probabilistic transitions) by calculating expected values across stochastic outcomes.
  • Monte Carlo Tree Search (MCTS): Balances exploration and exploitation via UCT (Upper Confidence bounds for Trees); selection, expansion, simulation, backpropagation.
04 / IN-DEPTH SYLLABUS MODULES

Core Theoretical Modules

Comprehensive subject breakdown containing foundational principles, key theorems, and common examination pitfalls.

MODULE 01

State-Space Formulation & Informed Search (A*)

  • State space 5-tuple: Initial state, action set, transition model, goal test, path cost function.
  • Uniform-Cost Search expands node with lowest path cost g(n). Equivalent to Dijkstra on graphs with arbitrary step costs.
  • A* Search expands node with lowest evaluation function f(n) = g(n) + h(n).
  • Heuristic Admissibility: h(n) never overestimates actual cost to goal: h(n) <= h*(n) for all n.
Essential Theorem & Principle A* Graph Search Optimality: If heuristic h(n) is consistent (monotonic), A* graph search using a closed list is guaranteed to find an optimal solution without ever needing to reopen closed nodes.
⚠️ GATE Exam Trap & Common Mistake Admissibility vs Consistency: In A* GRAPH search, admissibility alone does NOT guarantee finding the optimal path if visited nodes are closed permanently. Monotonicity (consistency) is required!
MODULE 02

Adversarial Game Search & Alpha-Beta Pruning

  • Minimax: Computes optimal game value recursively. MAX chooses child with highest value; MIN chooses lowest.
  • Alpha (alpha): Best value that MAX can guarantee along the path to the current state.
  • Beta (beta): Best value that MIN can guarantee along the path to the current state.
  • Pruning Condition: Prune child subtree whenever beta <= alpha.
Essential Theorem & Principle Alpha-Beta Invariant: Alpha-beta pruning visits strictly fewer game tree nodes than standard minimax while computing the EXACT same minimax value at the root.
⚠️ GATE Exam Trap & Common Mistake Pruning Cutoff Threshold: Pruning occurs only when beta <= alpha, never when beta > alpha. If beta > alpha, the search must continue exploring siblings.
MODULE 03

Constraint Satisfaction & Bayesian Belief Networks

  • CSP: Solved by Backtracking Search augmented with Minimum Remaining Values (MRV) and Least Constraining Value heuristics.
  • AC-3 Arc Consistency: Enforces that for every value in domain of X, there exists a consistent value in domain of Y.
  • Bayesian Network: Directed Acyclic Graph where joint distribution is product of conditional probabilities P(X_i | Parents(X_i)).
  • D-separation: Formal graphical criterion for determining whether X is conditionally independent of Y given evidence Z.
Essential Theorem & Principle Bayesian Chain Rule Factorization: Any Bayesian Network represents a joint probability distribution over variables X_1, ..., X_n as P(X_1, ..., X_n) = prod_{i=1}^n P(X_i | Parents(X_i)).
⚠️ GATE Exam Trap & Common Mistake Collider (V-Structure) Conditional Dependence: In a collider structure A -> C <- B, variables A and B are marginally independent. However, conditioning on C (or any descendant of C) makes A and B CONDITIONALLY DEPENDENT!
05 / CANONICAL COMPARISON MATRIX

A* Graph Search vs. Greedy Best-First Search

Detailed architectural and mathematical comparison of fundamental contrasting concepts frequently tested in GATE:

COMPARISON DIMENSION A* Search Algorithm Greedy Best-First Search
Node Evaluation Function f(n) = g(n) + h(n), where g(n) is exact cost from start, and h(n) is heuristic estimate to goal. f(n) = h(n), evaluates node exclusively on estimated proximity to goal.
Optimality Guarantee Guaranteed optimal if h(n) is admissible (tree search) or consistent / monotonic (graph search). Not optimal; easily misled by false local heuristic gradients into costly sub-optimal paths.
Completeness Property Complete on finite graphs; complete on infinite graphs if edge costs >= epsilon > 0. Incomplete in infinite state spaces or graphs with cycles (can enter infinite loops without cycle checking).
Search Space Exploration Expands all nodes in concentric equicost contours where f(n) < C*. Plunges aggressively toward goal regardless of path cost accumulated; behaves like greedy DFS.
Worst-Case Complexity Time O(b^d) and Space O(b^d) where b is branching factor and d is solution depth. Time O(b^m) and Space O(b^m) where m is maximum depth of the state space.
GATE Examination Pitfall Consistency (Monotonicity) requires h(n) <= c(n, a, n') + h(n'). Every consistent heuristic is admissible, but NOT vice versa. Greedy Best-First search can expand fewer nodes than A* on simple mazes, but produces longer total paths.
06 / MATHEMATICAL FORMULATION

A* Search Admissibility & Alpha-Beta Pruning

Heuristic Search & AI 
A* Evaluation Function:
  f(n) = g(n) + h(n)
  g(n): Exact cost from start node to current node n.
  h(n): Estimated cost from node n to goal.
Admissibility Condition:
  h(n) <= h*(n) for all n (h never overestimates actual cost).
  => Guarantees finding optimal path on tree search!
Consistency (Monotonicity):
  h(n) <= c(n, a, n') + h(n')
  => Ensures f(n) is monotonically non-decreasing along any path.
