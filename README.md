## 🏛️ Curriculum Architecture & Academic Tracks

The portal organizes the full 16-subject GATE curriculum into three distinct, structured academic tracks:

```
                                  GATE 2027 CURRICULUM
                                            │
        ┌───────────────────────────────────┼───────────────────────────────────┐
        ▼                                   ▼                                   ▼
[Track I: Foundational Convergence]   [Track II: Classical Systems]   [Track III: Applied Intelligence]
   Dual-Track Core (CS & DA)                 CS Track                             DA Track
     • Linear Algebra                  • Discrete Mathematics              • Machine Learning
     • Calculus & Optimization         • Digital Logic                     • Artificial Intelligence
     • Probability & Statistics        • Computer Organization
     • Programming & Data Struct.      • Theory of Computation
     • Algorithms                      • Compiler Design
     • Databases & Data Warehousing    • Operating Systems
     • General Aptitude                • Computer Networks
```

### 1. Foundational Convergence · Dual-Track Core (CS & DA)
Seven high-yield mathematical, algorithmic, and data foundations universally tested across both examination papers:
* **Linear Algebra**: Matrix rank, determinants, systems of linear equations, eigenvalues/eigenvectors, LU decomposition, vector spaces, and Singular Value Decomposition (SVD).
* **Calculus and Optimization**: Limits, continuity, differentiability, maxima/minima, Mean Value Theorems, Taylor series, and gradient-based unconstrained optimization.
* **Probability and Statistics**: Axioms of probability, Bayes' Theorem, discrete & continuous distributions (Gaussian, Poisson, Binomial), expectation, covariance, Central Limit Theorem, and hypothesis testing.
* **Programming and Data Structures**: Pointer arithmetic, recursion, stacks, queues, linked lists, binary trees, AVL trees, and binary heaps.
* **Algorithms**: Asymptotic complexity analysis, divide-and-conquer, Master Theorem, greedy algorithms, dynamic programming, graph traversals (BFS/DFS), and shortest paths (Dijkstra, Bellman-Ford).
* **Databases and Data Warehousing**: ER modeling, relational algebra, SQL queries, functional dependencies, 1NF to BCNF normalization, transaction processing, ACID properties, and dimensional modeling.
* **General Aptitude**: Quantitative reasoning, time-work equivalence, data interpretation, verbal ability, syllogisms, and spatial reasoning.

### 2. Classical Computing Systems & Theoretical Foundations Track (CS)
Seven core computer science engineering disciplines covering processor architecture, system software, networking, and the foundations of computation:
* **Discrete Mathematics**: Propositional & predicate logic, sets, relations, partial orders, lattices, monoids, groups, graph coloring, and recurrence relations.
* **Digital Logic**: Boolean algebra, Karnaugh map minimization, multiplexers, decoders, flip-flops, synchronous counters, and setup/hold timing analysis.
* **Computer Organization and Architecture**: Instruction cycle, addressing modes, pipeline hazards, cache memory hierarchy, effective memory access time, and DMA.
* **Theory of Computation**: Regular languages, DFA/NFA, state minimization, Pumping Lemma, context-free grammars, pushdown automata, Turing machines, and undecidability.
* **Compiler Design**: Lexical tokenization, LL(1) parsing with FIRST & FOLLOW sets, LR/LALR parsing tables, syntax-directed translation (SDT), and intermediate code generation.
* **Operating Systems**: Process lifecycle, CPU scheduling, semaphores, Banker's safety algorithm for deadlocks, paging, TLB address translation, and virtual memory.
* **Computer Networks**: OSI & TCP/IP models, CSMA/CD, IPv4 CIDR subnetting, distance-vector and link-state routing, and TCP congestion control dynamics (AIMD).

### 3. Applied Intelligence, Machine Learning & Statistical AI Track (DA)
Two specialized domains dedicated to modern statistical learning, deep representations, heuristic search, and probabilistic inference:
* **Machine Learning**: Supervised regression and classification (linear, ridge, logistic), SVM with kernel trick, decision trees, bias-variance decomposition, K-means clustering, and PCA dimensionality reduction.
* **Artificial Intelligence**: Informed and uninformed graph search, A* heuristic admissibility and consistency, minimax game trees with alpha-beta pruning, and Bayesian Belief Networks.

* **Official Visual Study Guide Dossiers**: Features complete, verified visual handbooks with direct PDF downloads:
  * **Algorithms (41 Pages · `assets/docs/AW+ALGO.pdf`)**: Asymptotic Analysis, Extended Master Theorem, Divide & Conquer bounds, Greedy proofs, and Dynamic Programming.
  * **Compiler Design (33 Pages · `assets/docs/compiler-design-visual-study-guide.pdf`)**: 6-Phase Pipeline, LL(1) and LR/LALR Parsing, Lexical maximal munch, SDT/SDD attribute evaluation, TAC/SSA IR, Basic Blocks, and 7 Code Optimization passes.

* **Zero-Flash Theme Persistence**: Inline theme initialization eliminates dark-mode flickering on page refresh.
* **Mac-Style Glassmorphism Window Chrome & 3D Kinetic Canvas**: Real-time interactive particle physics simulating topological surfaces and search states.
* **Universal Command Palette (Spotlight / `⌘K`)**: Instant fuzzy search across all 16 subjects, core topics, and reference formulas with arrow-key navigation.
* **Persistent Study Docket & Pomodoro Timer**: Queue subjects into a persistent local docket with an integrated 25-minute Pomodoro revision timer.

## 🚀 Local Development & Verification

Serve locally with Python:

```bash
# Clone the repository
git clone https://github.com/Arshad9999/Study-Gate-Exam-with-Arshad.git
cd Study-Gate-Exam-with-Arshad

# Run local HTTP server
python3 -m http.server 8000
```

Open [http://localhost:8000/](http://localhost:8000/) in your browser.

### Automated Test Suite
To verify syllabus schema integrity, route completeness, and paper mappings:
